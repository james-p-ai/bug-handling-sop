What happens

Signed-in intake → GitHub issue + Bug Report board

  1. Sign in to BookIQ and open Report a problem (user menu or side nav), or use the button above.
  2. Answer two questions: what you were trying to do, and what happened instead.
  3. You get a Reference #N — no GitHub URL in the product UI.
  4. Our team gets a structured issue on Book-IQ/bookiqv1-rc and a card on the Practical Office Bug Report project.

Hard truth

Do not file BookIQ client reports as issues on this training repo. Use the in-app form so tenant, user, and environment context ride along with the submission.

Environments

Where to open the form

  • Dev — app.dev.bookiq.io/report-bug (day-to-day)
  • Staging / UAT — app.staging.bookiq.io/report-bug when that environment is in use
  • Production — same path on the production BookIQ host when intake is enabled there

Canonical in-app route: /t/:tenantId/help/report-bug. The short /report-bug alias redirects to your default tenant.
